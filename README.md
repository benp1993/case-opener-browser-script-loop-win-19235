## Overview

Case-opener vBrowser is a browser-based game utility designed around a case opening gameplay loop. It focuses on a compact HTML-driven setup that works well in web hosting environments and can also be used locally without requiring a separate launcher.

The utility is aimed at a Counter Strike-inspired presentation and keeps the experience lightweight. It emphasizes simple controls and adjustable behavior so the pace of the loop can be tuned without adding a heavy interface or extra dependencies.

## Script Features

- Browser-based execution for web and HTML gameplay environments
- Case opening loop centered on quick repeatable interaction
- Adjustable speed control for pacing the sequence
- Adjustable friction control for motion feel and response
- No launcher required for use in supported setups
- Local play support for offline or self-hosted use
- Web hosting support for easy browser deployment
- Lightweight structure suited to simple game utility workflows
